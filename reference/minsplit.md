# Age- and Sex-stratified Samples for Michigan data

A 4-dimensional `array` of samples generated by the MSTCAR Gibbs sampler
for demonstration with [`split_sample_groups()`](split_sample_groups.md)

## Usage

``` r
minsplit
```

## Format

\`minsplit\` a small sample dataset to be used for demonstration with
[`split_sample_groups()`](split_sample_groups.md). Generated by an
MSTCAR model with two regions, six age-sex groups, and three time
periods.
